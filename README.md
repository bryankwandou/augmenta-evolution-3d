# Augmenta — Human Evolution Cybernetic 3D Experience

Interactive real-time WebGL + 3D cybernetic dermal implant simulation with responsive molten-orange sub-dermal circuitry, titanium/carbon-fiber plate telemetry, and concentric orbital biometrics.

## Stack
- React 19 + TypeScript + Vite
- Three.js WebGL + custom GLSL depth-displaced cybernetic portrait & sub-dermal molten circuit shader
- Interactive orbital telemetry nodes & biometric schematic inspector
- Tailwind CSS v4 design tokens
